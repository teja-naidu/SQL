# Day 1 Insights - Loan Portfolio Overview

## Dataset Overview

* Total Loan Applications: 38,576
* Total Funded Amount: $435.76 Million
* Total Amount Received: $473.07 Million
* Average Loan Amount: $11,296.07
* Average Interest Rate: 12%
* Average Debt-to-Income (DTI) Ratio: 13%

## Key Findings

### Loan Portfolio Size

* The institution processed 38,576 loan applications, demonstrating a large-scale lending portfolio.
* More than $435 million was funded to borrowers across multiple loan categories.

### Repayment Performance

* The total repayment amount received was approximately $473 million.
* Total repayments exceeded the funded amount, indicating revenue generation through interest and successful loan servicing.

### Borrower Analysis

* The average loan amount issued was $11,296.
* Borrowers maintained an average DTI ratio of 13%, suggesting relatively healthy financial profiles.

### Interest Rate Analysis

* The average interest rate across the portfolio was 12%.
* This reflects a balanced lending strategy that supports both profitability and borrower affordability.

### Loan Status Distribution

| Loan Status | Total Loans |
| ----------- | ----------: |
| Fully Paid  |      32,145 |
| Charged Off |       5,333 |
| Current     |       1,098 |

### Portfolio Health

* Fully Paid loans represent the majority of the portfolio.
* Charged Off loans account for a smaller portion and indicate potential credit risk exposure.
* Current loans continue to contribute to active repayment activity.

## Business Value

This analysis provides a high-level understanding of portfolio size, repayment behavior, borrower financial health, and overall loan performance. These insights help lending institutions monitor profitability, manage risk, and support strategic lending decisions.
